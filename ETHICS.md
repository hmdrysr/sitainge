# Ethics

- Speaker communities own their language. The project serves them first.
- Informed consent is required for every recording and personal contribution.
- Consent states: public, research-only, restricted, private, withdrawn, permission pending.
- Withdrawal is honoured going forward; the audit trail records that it occurred without retaining withdrawn content in public layers.
- Sensitive or cultural material may be restricted at the community's request.
- No personal information is published without consent. Private metadata is stored separately.
- This repository is CC0 and therefore Open. The other access classes (Research access, Restricted, Closed) apply only to material held in the external long-term archive, never in this repository. Each restriction states its reason.
- CC0 is irrevocable once published. Contributors are told this before submitting.
- Fieldwork follows documentary-linguistics practice (see source register for the standards still to be reviewed).
