# Site copy changes (October 8, 2026)

Scope: landing page, dictionary, translator, contribution form, browser extension, website README, `facts.json` and video labels. Rules applied: `docs/style/canadian-style-guide.md`. Facts and source links are unchanged; honesty caveats were kept or made more exact.

## Project-name decisions

- The header brand, page titles, extension name and web app name read **siṭaiṅge** (the project).
- The language is **siṭaiṅga** in text about the language. The landing page hero states that the language is siṭaiṅga, known in English as Chittagonian. The repository and web address keep **Sitainge**.
- Submission file names, email subjects and share titles keep the repository form "Sitainge submission" so reviewer tools still match them.

## Other changes

- Hand-drawn tool-card SVGs replaced with Tabler icons (book, search, language, puzzle) through `ui-icons.js`; the play button uses the Tabler player-play icon. The dictionary word picture was removed as decorative.
- All pages now share `site.css`, one header and one accent. Inline style attributes in the contribution form (progress bar, hidden copy field) were replaced with CSSOM and classes because the CSP blocks them.
- Dates now read "October 8, 2026"; "per cent" in prose; metric units with the original in parentheses.
