# Contributing

**Recommended route:** the chatbot interview in `contribute/README.md`. It produces a file ready to submit. A chatbot that can create GitHub issues can submit the file on the contributor's behalf, with permission.

Contributors do not need to know YAML, Git or linguistics. Use the issue forms under **Issues > New issue**, or send audio and notes to the project steward.

The project accepts the following submissions: a word, a variant, a grammar observation, a pronunciation, a regional difference, a proverb, an idiom, a song, a story, a place name or an oral history, a correction, a source, a research question, a possible Rohingya relationship, or an orthographic proposal.

Contributors should state what they know and how they know it: who said it, where the speaker is from, roughly what age group the speaker belongs to, and whether a recording exists. Where the contributor is unsure, they should write "not sure." That is useful evidence.

A submission is a contribution, not an automatic acceptance. Reviewers assess it, and disagreement is recorded rather than erased.

Licence and consent: public contributions are dedicated to the public domain under CC0 1.0, and the dedication cannot be undone once published. A contributor who is unsure should choose "Discuss first," and nothing will be published. Recordings that must stay research-only, restricted or private are not uploaded here; contact the project steward about the archive. Speakers are identified by ID (for example `CTG-SPK-00041`), not by name, unless they consent.

Credit: a contributor may be credited by name, by contributor ID, or anonymously.

## Spelling and IPA

Chittagonian has no established spelling, so no spelling is wrong. Contributors should write the language as they would type it to a friend. A form is described as "not Chittagonian" only if speakers do not use it. Contributors do not need to write IPA. Formal International Phonetic Alphabet (IPA) forms are added later from recordings or sound descriptions, and the source of each is recorded (see D-014 to D-016 in `docs/governance/decision-log.md`).

## Other ways to help

- **Check an entry.** Open the dictionary (`website/dictionary/`) and use the correction link on any entry, or edit the record's file directly. Corrections appear in every tool.
- **Moderate.** Moderators review learning videos and photographs; see `docs/contribute/moderators.md`.
- **Record or interview speakers.** Follow the protocols in `docs/protocols/`, beginning with the consent form template.
- **Write code or documentation.** Follow `docs/style/canadian-style-guide.md` for prose, `docs/dadi/UX_RESEARCH.md` for interface work and `AGENTS.md` if an AI assistant is involved.
